# Igloo Site

연간 목표를 세우고 달성 과정을 기록하는 앱 Igloo의 공식 웹사이트.

- 사이트 주소: https://igloo.page
- 배포: Cloudflare Pages
- 배포 브랜치: `main`

## 파일 구성

- `public/index.html` — Igloo 소개 페이지
- `public/app-ads.txt` — AdMob 광고 판매자 확인 파일

## 배포

`main`에 변경 사항을 반영하면 Cloudflare Pages가 `public/` 폴더를 자동으로 배포합니다.
배포 후 `https://igloo.page/app-ads.txt`에서 파일이 정상적으로 열리는지 확인합니다.
